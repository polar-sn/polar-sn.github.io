Docusaurus 블로그 개발

2025년 1월 21일 · 약 4분

삽질하고 공부하던 기억이 잊혀지는 게 아까워 글로 남겨야지 생각만하다가 드디어 블로그를 만들고 첫 포스트를 작성하였다.

첫 포스트에는 이 블로그를 만드는 여정을 담았다.

어떤 플랫폼을 사용할까​

블로그를 개설하려면 어느 폴랫폼을 이용해 블로그를 운영할지 정해야한다. 국내에서 많이 사용하는 블로그 플랫폼으로는 네이버 블로그, 티스토리가 있고, 최근에는 브런치, 깃허브, 미디엄, 노션, 워드프레스, 벨로그 등 목적과 선호에 맞게 정말 다양한 플랫폼이 존재한다.

[각 블로그 플랫폼 장단점]

네이버 블로그티스토리
장점- 높은 국내 노출량 - 운영의 편리함- ㄴ네ㄴAll major browsers
단점- 상업적 성격이 강해 퍼스널 브랜딩으로 적합하지 않음 - 하락중인 네이버 검색 점유율, 높아진 구글 검색 비중Programed Trusted TypesOrigin

나는 기술 블로그를 목적으로 하고 있으므로 기본적으로 마크다운과 코드 하이라이팅을 지원하는지, 그리고 추가로 깔끔한 디자인을 제공하는지 고려하였다.

고민하던 부분은 꾸준히 쓰려면 막 써야 할거 같은데, 그러려면 티스토리나 벨로그와 같은 플랫폼이 좋을 거 같고, 그러자니 그래도 컴퓨터 전공자로써 github pages에 블로그를 구축해 보고 싶은 욕심도 피어났다.

고민 끝에 좀 더 도전적인 게 더 끌렸고, 최근에 웹 개발에 많이 사용되는 Javascript + React 조합의 플랫폼을 다뤄보고 싶었다.

크게 아래와 같은 기능을 기준으로 플랫폼을 선정하였다.

  • 마크다운 지원
  • 코드 하이라이팅 지원
  • 깔끔한 디자인
  • 트렌디한 플랫폼
  • 활성화된 커뮤니티

최종적으로, Github Pages를 이용해 Docusaurus 기반의 블로그를 만들기로 결정하였다.

Docusaurus란​

Docusaurus는 JAM Stack을 활용한 정적 사이트 생성기(Static Site Generator)로, JAM Stack은 주로 JavaScript, API, Markup(HTML/CSS)을 사용하여 웹 사이트를 구축하는 방법을 말한다.

JAM Stack을 이용한 정적 사이트 생성기 리스트는 여기서 확인할 수 있다.

가장 인기가 많은 프레임워크는 Javascript + React 조합인 Next.js이지만, 주로 서버 사이드 렌더링을 위해 사용하는 프레임워크라고 하여 그 다음으로 많이 사용 중이 Docusaurus를 선택하였다.
